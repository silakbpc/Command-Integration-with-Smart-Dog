# 🐶 Command Integration with Smart Dog

This project is an artificial intelligence-supported system that allows you to guide a smart dog using voice commands. 🎙️🐾
It analyzes the voice commands received from the user with an artificial neural network model and makes the dog do the appropriate movements.

## 🚀 Features

- ✅ Voice command recognition
- ✅ Command classification with artificial neural network
- ✅ Synchronization of dog movements with commands
- ✅ A fun, educational and interactive experience

## 🛠️ Technologies Used

- **Python 3.10**
- **TensorFlow & Keras**
- **TensorBoard** (For model training and visualizations)
- **Voice recognition libraries**
- **Machine Learning**

## 🔍 How Does It Work?

1. **Voice Command Reception:**
The voice command given by the user is received via the microphone.

2. **Model Training:**
The artificial neural network model is trained using voice data.

3. **Command Classification:**
The trained model identifies the given voice command and decides on the appropriate action.

4. **Movement Implementation:**
The dog moves in accordance with the command and the user is notified in case of success.
